
# 🍽️ FOODIES DELIGHT

**FOODIES DELIGHT** is a beautifully crafted food recipe website where food lovers can explore, discover, and fall in love with a wide variety of mouthwatering recipes. Whether you're a home cook or just browsing for your next meal inspiration — this site is your go-to culinary companion.

🌐 **Live Site:** [foodies-delight-proj.vercel.app](https://foodies-delight-proj.vercel.app/)  
📦 **GitHub Repo:** [github.com/KL2400030188/FOODIES-DELIGHT-PROJ](https://github.com/KL2400030188/FOODIES-DELIGHT-PROJ)

---

## 🎯 Features

- 🗂️ **Browse Recipes** – Explore a variety of delicious and curated food recipes.  
- 📖 **Detailed Recipe View** – Get full cooking instructions, ingredients, and images.  
- 🌐 **Responsive Design** – Optimized for all screen sizes (mobile, tablet, desktop).  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, JavaScript  
- **Styling:** CSS  
- **Deployment:** Vercel
